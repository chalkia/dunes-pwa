# Θίνες Ρεθύμνου — εφαρμογή πεδίου (PWA)

Εφαρμογή για tablet. Υλοποιεί το «Πρωτόκολλο πεδίου» (29–31/10/2026).
Δουλεύει χωρίς σύνδεση. Έχει χάρτη, κάμερα και εξαγωγή για Google My Maps / GIS.

## Τι κάνει

- **Φύλλο 1:** ταυτότητα έρευνας, θέση αρχής και τέλους διατομής.
- **Φύλλο 3:** τετράγωνα 1×1 μ. (ζώνη 0–4, % κάλυψη, είδη, κρινάκια), πιέσεις, εισβλητικά, άγνωστα φυτά, αλλαγές ζώνης.
- **Φύλλο 4:** βαθμολογία υγείας 0–10 με το «Γιατί;», τρεις εντυπώσεις, πρόταση προστασίας.
- **Χάρτης:** η περιοχή από το KMZ, σύμβολα όπως στο πρωτόκολλο, δορυφορικό υπόβαθρο ή χάρτης.
- **Κάμερα:** φωτογραφίες σε κάθε καταγραφή. Σμικρύνονται αυτόματα. Ονομάζονται `Παραλία_ημερομηνία_ομάδα_T10_τετράγωνο.jpg`.
- **Φυτά:** οδηγός με 10 φωτογραφίες για κάθε είδος (offline). Πηγή: iNaturalist, άδειες Creative Commons (δημιουργός και άδεια φαίνονται σε κάθε φωτογραφία). Μόνο για εκπαιδευτική χρήση.
- **Γράφημα:** % κάλυψη ανά απόσταση από τη θάλασσα (για το μάθημα στην τάξη).

## Θέση χωρίς GPS

Τρεις τρόποι. Μπορείς να τους συνδυάσεις.

1. **GPS τώρα.** Αν το tablet έχει GPS.
2. **Στον χάρτη.** Πατάς πάνω στον χάρτη, ακόμη και πρόχειρα.
3. **Αργότερα.** Αφήνεις το σημείο χωρίς θέση και το τοποθετείς στο σχολείο (κουμπί «Βάλε στον χάρτη»).

Κόλπος: βάλε μόνο **αρχή και τέλος** της διατομής. Κάθε τετράγωνο με απόσταση παίρνει θέση μόνο του, πάνω στην ευθεία (σήμανση «υπολογισμένη»).

## Πώς ανεβαίνει στον κοινό χάρτη

1. Κάθε ομάδα: καρτέλα **Αποστολή** → «Πακέτο ZIP». Το στέλνει στον/στην εκπαιδευτικό (Drive, email).
2. Στο <https://mymaps.google.com>: νέος χάρτης → Εισαγωγή → `points_mymaps.csv` κάθε ομάδας.
3. Στήλες θέσης: `Latitude`, `Longitude`. Τίτλος: `Όνομα`. Ένα επίπεδο ανά ομάδα, στον ίδιο χάρτη.
4. Για QGIS ή άλλο GIS: `data.geojson`. Για Google Earth: `.kmz` (έχει και τις φωτογραφίες).

Εναλλακτικά, ο/η εκπαιδευτικός φορτώνει όλα τα ZIP στην ίδια εφαρμογή («Εισαγωγή») και κάνει μία εξαγωγή για όλους.

## Δοκιμή στο tablet — ΠΡΙΝ από την 29/10

Κάν’ το σε **κάθε** tablet, στο σχολείο, με wifi.

1. Άνοιξε τον σύνδεσμο της εφαρμογής (Chrome σε Android, Safari σε iPad).
2. Εγκατέστησέ την στην αρχική οθόνη.
3. Καρτέλα **Αποστολή** → κατέβασε και τους δύο χάρτες. Περίμενε το ✔.
4. Δώσε άδεια θέσης όταν ζητηθεί. Δοκίμασε «GPS τώρα».
5. **Βάλε το tablet σε λειτουργία πτήσης.** Άνοιξε την εφαρμογή.
6. Φτιάξε μια δοκιμαστική διατομή. Κάνε ένα τετράγωνο με φωτογραφία. Δες το στον χάρτη.
7. Κάνε «Πακέτο ZIP». Έλεγξε ότι ανοίγει.
8. Καρτέλα Αποστολή → «Διαγραφή όλων», για να ξεκινήσεις καθαρά.

Η κάρτα «Έτοιμο για εκτός σύνδεσης;» στην πρώτη καρτέλα πρέπει να έχει ✔ στα τρία.

## Δημοσίευση (GitHub Pages)

Η εφαρμογή θέλει διεύθυνση **https**. Αλλιώς δεν δουλεύουν η κάμερα, η θέση και η λειτουργία εκτός σύνδεσης.

**Επιλογή Α — απλή:** ανέβασε τον φάκελο σε repo. Settings → Pages → Deploy from a branch → `main` / root.

**Επιλογή Β — με φύλακες:** το αρχείο `.github/workflows/pages.yml` τρέχει τους ελέγχους πριν από κάθε δημοσίευση. Αν βρουν πρόβλημα, δεν δημοσιεύει. Ρύθμιση: Settings → Pages → Source: **GitHub Actions**.

Έτοιμη εντολή για το Gemini (Antigravity):

```
Πάρε τον φάκελο dunes-pwa και ανέβασέ τον σε νέο repo GitHub με όνομα "dunes-pwa" (public).
Ενεργοποίησε GitHub Pages με Source = GitHub Actions (το workflow υπάρχει στο .github/workflows/pages.yml).
Περίμενε να τρέξει το workflow. Δώσε μου τον σύνδεσμο https. Μην αλλάξεις κανένα αρχείο κώδικα.
```

## Έλεγχος κώδικα (για όποιον αλλάζει την εφαρμογή)

```
cd tools && npm install     # μία φορά
cd .. && npm run check
```

Ελέγχει: σύνταξη, εισαγωγές/εξαγωγές, ανύπαρκτα στοιχεία HTML, αρχεία του service worker, στήλες εξαγωγής, ανύπαρκτες μεταβλητές.
Τρέξε τον πριν από κάθε commit. Αν βρει κάτι, διόρθωσε τον κώδικα ή τον φύλακα. Μην κρύψεις το εύρημα.

## Γνωστά όρια

- **Δεν ανεβαίνει μόνη της** στο Google Maps. Χρειάζεται εξαγωγή και εισαγωγή (βλ. παραπάνω). Αυτόματη αποστολή σε κοινή βάση (π.χ. Supabase) είναι δυνατή ως επόμενο βήμα.
- **Φωτογραφίες στο My Maps:** το CSV δεν τις μεταφέρει. Μένουν στο ZIP/KMZ. Στο My Maps μπαίνουν χωριστά.
- **Ο χάρτης εκτός σύνδεσης** καλύπτει μόνο την περιοχή της δράσης και ένα περιθώριο ~400 μ.
- **Τα δεδομένα μένουν στο tablet.** Κάν’ εξαγωγή στο τέλος της μέρας. Μην καθαρίσεις τα δεδομένα του browser πριν την εξαγωγή.
- **Πηγές χάρτη:** Esri World Imagery και OpenStreetMap. Έλεγξε τους όρους τους αν η εφαρμογή γίνει δημόσια ή εμπορική.
- **% κάλυψη:** η εφαρμογή θεωρεί ότι τα «εισβλητικά» είναι μέρος των «φυτά σύνολο». Γυμνή άμμος + νεκρά υλικά + φυτά ≈ 100%.
